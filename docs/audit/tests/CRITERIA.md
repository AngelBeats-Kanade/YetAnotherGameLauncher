# Phase 1 测试审计判定标准（全案统一口径）

- 实测日期：2026-09-19；探针校准依据：`docs/audit/phase0/DISPATCH-PROBE.md`

## 三档判定

| 判定 | 含义 |
|---|---|
| ✅ 正确 | 断言真实执行且失败会传播；断言被测行为而非镜像自身；确定性（无外网/无裸时序）；无静默跳过分支 |
| ⚠️ 存疑 | 当前能红能绿但存在缺陷：违纪形态、锁死序列化格式、脆弱时序、孤儿续体竞态、低可维护性。修复但不按 bug 计 |
| ❌ 错误 | 假绿（断言被吞/不执行）、空心（失败代码也能通过）、零断言路径、静默平台早退、依赖外网必挂 |

默认怀疑：论证不出 ✅ 就落 ⚠️/❌。

## 机制规则（探针/文档实锤）

- D1：`Dispatch(Func<Task>...)`（async lambda）**全形态吞断言**（Probe2/3 实锤）→ lambda 内有任何断言即 ❌；有真 await 即孤儿续体竞态 ⚠️+。修复 = 会话启动后测试线程直调服务，或同步交互外移断言。
- D2：`Dispatch(Action...)` 同步 lambda 内断言**可传播**（Probe1 实锤）→ 单纯断言在内 = ⚠️ 违纪（AGENTS.md 纪律要求外移）；Phase 2 统一外移。
- D3：平台早退 `if (!IsLinux) return;` 使另一半 CI 零断言静默绿 = ❌（修复 = 平台适配断言或显式跳过标记）。
- D4：落盘 JSON 对原始文本 Contains = ⚠️（转义可骗过 + 锁死序列化格式）；修复 = 反序列化断模型值。
- D5：固定 `Task.Delay/Thread.Sleep` 后断言"未发生"或跨线程落位 = ⚠️（重负载 CI 假绿/假红双向风险）；带条件有界轮询 = ✅。
- D6：外网真实请求 = ❌（离线必挂或空图仍绿）。
- D7：辅助方法静默 return 使整组断言蒸发 = ❌。
- D8：VM 层 `Command.Execute` 冒充视图层覆盖 = ⚠️（该层已有真实指针回归时；否则按缺口计）。

G4 路径断言分隔符单侧归一；G5 窄窗口未解除 MinWidth=920；G6 最大化未按工作区定尺寸；
